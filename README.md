## 📌 Overview

An interactive video platform that lets users watch video streams in real-time and submit star ratings and feedback. Built to be responsive, fast, and easy to deploy via GitHub Pages.

## 🌟 Key Features

* **🎥 HD Video Streaming:** Smooth in-browser playback with custom video controls.
* **⭐ Interactive Rating System:** Submit instantaneous 1–5 star ratings and written reviews.
* **📊 Aggregate Feedback:** Real-time updates showing average ratings and score distributions.
* **📱 Mobile Responsive:** Optimized for desktop, tablet, and mobile browsers.
